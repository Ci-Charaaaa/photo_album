这是一个用于管理照片的贵个人软件项目。该项目旨在帮助用户轻松地管理、浏览他们的照片。
无论是普通照片库还是专业摄影作品集，这个软件都提供了丰富的功能来满足用户的需求。

注意：本项目旨在帮助作者学习工程实践和软件开发技能，并不打算用于商业用途。请勿将其用于任何商业活动或盈利目的。
当然，如果你对这个项目感兴趣，欢迎参与贡献代码、提出建议或报告问题。你的反馈将有助于改进这个项目，使其更加完善和实用。


技术栈：采用基于NET8+平台的技术栈，结合前端框架avalonia和SQLite数据库，实现了一个完整的照片管理系统。

项目采用分层解耦的架构，具体模式以MVVM为主，具体分层为五层，分别为：Presentation层、ViewModels层、Application层、Domain层、Infrastructure层。
即前端UI层、视图模型层、应用服务层、领域模型层和基础设施层。每一层都有明确的职责和功能，确保系统的可维护性和可扩展性。
